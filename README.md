# SMS → Telegram

Небольшое Android-приложение: ловит входящие SMS и пересылает **отправителя + текст**
в заданный Telegram-чат через Bot API. Токен и chat_id задаются в самом приложении.

Только для личного использования на **своём** устройстве.

---

## 1. Подготовить Telegram-бота (без кода, ~5 минут)

1. В Telegram открой **@BotFather** → команда `/newbot` → задай имя.
   Получишь **токен** вида `123456789:AAE...`.
2. Найди своего бота по имени и напиши ему любое сообщение (например «привет»).
3. Открой в браузере:
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   Найди в ответе `"chat":{"id": ... }` — это твой **chat_id**
   (для личного чата это число, может быть отрицательным для групп).

Токен и chat_id понадобятся при первом запуске приложения.

---

## 2. Открыть и собрать в Android Studio

1. Запусти **Android Studio** → `File → Open` → выбери папку `sms-to-telegram`.
2. Дождись окончания **Gradle Sync** (Studio сама скачает Gradle 8.9, AGP и зависимости).
   При первом запросе согласись установить нужные компоненты SDK (compileSdk 34).
3. Подключи телефон по USB с включённой **отладкой по USB**
   (Настройки → Для разработчиков → Отладка по USB), либо запусти эмулятор.
4. Нажми ▶ **Run 'app'** — Studio соберёт debug-APK, установит и запустит.

> Собрать APK без запуска: `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
> Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

---

## 3. Настроить на устройстве

1. В приложении вставь **Bot token** и **Chat ID**, нажми **Сохранить**.
2. Выдай разрешение **на приём SMS**, когда появится запрос (или кнопкой «Запросить разрешение»).
3. Нажми **Отправить тестовое сообщение** — в чате должно появиться
   «✅ Тест: приложение подключено к Telegram».
4. Отправь себе настоящую SMS с другого телефона для проверки.

### Важно: чтобы приложение не «засыпало»
Android может ограничивать фоновую работу. Открой
**Настройки → Приложения → SMS → Telegram → Батарея** и выбери
**«Без ограничений» / отключи оптимизацию батареи**. Иначе часть SMS может
не пересылаться, когда телефон спит.

## Как это устроено

| Файл | Назначение |
|------|-----------|
| `SmsReceiver.kt` | `BroadcastReceiver` на `SMS_RECEIVED`: читает SMS, запускает отправку |
| `TelegramClient.kt` | POST-запрос к `api.telegram.org/bot<token>/sendMessage` |
| `Prefs.kt` | Хранение токена и chat_id в `SharedPreferences` |
| `MainActivity.kt` | Экран настроек, запрос разрешения, тест |

## Разрешения
- `RECEIVE_SMS` — приём входящих SMS (выдаётся вручную при запуске).
- `INTERNET` — отправка в Telegram.

Приложение **не** запрашивает `READ_SMS` и не читает историю переписки —
только новые входящие сообщения в момент получения.

## Ограничения / на что обратить внимание
- Это debug-сборка для личного устройства, не для публикации в Google Play
  (Play сильно ограничивает SMS-разрешения).
- Токен хранится в приватных настройках приложения; не ставь сборку на чужие устройства.
- MMS не обрабатываются — только текстовые SMS (в т.ч. длинные/многочастные).
